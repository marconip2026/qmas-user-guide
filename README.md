# QMAS User Guide

Step-by-step guides with screenshots for every QMAS module.

Live site: https://marconip2026.github.io/qmas-user-guide/

## Structure

- `index.html`: list of all modules and flows
- `<module>/index.html`: one guide page per flow
- `<module>/img/`: screenshots, captured on the QMAS dev environment
- `dify/`: one PDF and one Markdown file per module for the QMAS chatbot knowledge base
